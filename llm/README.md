# LLM layer

Модуль `llm` изолирует сетевые модели от pipeline. Приложение передаёт уже
разрешённый `LLMClientConfig` и долгоживущий `httpx.AsyncClient` в
`get_llm_client()`. Адаптеры не читают environment, файлы конфигурации или
Windows Credential Manager и не закрывают внешний HTTP-клиент.

## Публичный контракт

- `find_entities(text, types)` возвращает точные `EntitySpan` только для
  запрошенных типов. Координаты вычисляются по исходной строке, а не принимаются
  от модели.
- `classify_party(context_snippet, candidate_name)` возвращает `supplier`,
  `buyer` или `None`, если модель ответила `unknown`.
- `list_llm_models()` приводит каталоги провайдеров к `LLMModelInfo`.
- `validate_llm_connection()` выполняет небольшой синтетический запрос и
  возвращает безопасный код результата.

Regex обрабатывает ИНН, КПП, ОГРН, телефон, email, банковский счёт, БИК и номер
договора. LLM ищет ФИО, организации, адреса и суммы, а также классифицирует роль
стороны.

## JSON-контракт

Корректные синтетические ответы:

```json
{"entities":[{"type":"organization","text":"ООО Тест"}]}
```

```json
{"role":"supplier"}
```

Полная Markdown-обёртка также принимается:

````text
```json
{"entities":[]}
```
````

Лишний текст, отсутствующие поля и повреждённый JSON приводят к
`LLMResponseError`. Неизвестный или незапрошенный тип пропускается. Если
возвращённое значение не встречается в исходной строке в точности, оно также
пропускается без вывода значения в лог.

## Настройка

Factory поддерживает `mock`, `gigachat`, `openai`, `anthropic`,
`openai_compatible`, `ollama` и `vllm`. Для сетевых провайдеров вызывающий код
обязан передать `httpx.AsyncClient`. Пользовательские URL принимают HTTPS;
обычный HTTP разрешён только для loopback-адресов.

`mock` детерминирован и не использует сеть. GigaChat использует OAuth key,
scope `GIGACHAT_API_PERS`, целевой API `https://api.giga.chat` и отдельный
проверенный TLS context приложения.

При выборе GigaChat, OpenAI или Anthropic анализируемый текст покидает компьютер
и передаётся выбранному поставщику. UI обязан сообщить об этом до сохранения
облачного провайдера. Ключи хранятся только backend в Windows Credential Manager,
не возвращаются через API и не попадают в логи.

## Контекст и проверка

LLM получает отдельные `TextBlock`, а не исходный файл целиком. Универсального
лимита символов в этом слое нет: допустимый контекст зависит от выбранной модели,
поэтому application layer должен разбивать чрезмерно большие блоки до вызова
клиента. Версия текущих промптов находится в `PROMPT_VERSION`.

Для локального воспроизведения используйте `MockLLMClient` и только синтетический
текст, например `Поставщик ООО Тест заключил договор № 7.`. Реальные документы и
их фрагменты нельзя добавлять в Git.
